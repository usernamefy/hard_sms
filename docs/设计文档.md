## 2. 架构设计（MVC）

```
sms/
├── main.go                  # 入口：初始化数据库 → 注册路由 → 启动服务
├── config/config.go         # 全局配置（端口、DB 路径、会话密钥）
├── database/database.go     # 数据库连接（只连接，不建表不写数据）
├── models/user.go           # M：用户模型 + 数据访问方法
├── controllers/
│   ├── user_controller.go   # C：登录页渲染 / 登录提交 / 登出
│   └── index_controller.go  # C：后台首页
├── middlewares/auth.go      # 登录校验中间件（未登录 302 → /login）
├── routes/routes.go         # 路由注册 + 会话中间件配置
├── views/                   # V：login.html / index.html
├── static/css/style.css     # 静态样式
├── docs/设计文档.md          # 本文档

```

**请求流转**：Request → 路由 → Auth 中间件 → Controller → Model(GORM) → MySQL → 视图渲染 → Response

## 3. 登录流程设计

```
用户访问后台 ──→ Auth 中间件检查会话 user_id
                    │ 无会话
                    ├──────────────→ 302 重定向 /login
                    │ 有会话
                    ▼
              进入后台页面
用户提交登录表单（POST /login）
      │
      ├─ 用户不存在 / MD5(密码) 不匹配 → 302 /login?error=用户名或密码错误
      ├─ 账号被禁用（status=0）      → 302 /login?error=账号已被禁用
      └─ 校验通过
           ├─ 写入会话（user_id / username / realname），Cookie 24h 有效
           ├─ UPDATE users SET last_login = now
           └─ 302 重定向 / （后台首页）
```

**安全设计**：
- 密码以 MD5 密文存储（32 位小写十六进制），登录时对表单密码做同样加密后比对
- 会话基于加密 Cookie（gin-contrib/sessions），HttpOnly，防 XSS 窃取
- 登录失败统一提示"用户名或密码错误"，不区分用户不存在/密码错误，防账号枚举
- 所有后台路由挂载 Auth 中间件，登出时清空会话

## 4. 数据库设计（MySQL）

数据库：MySQL（建议 5.7+ / 8.0），库名 `sms`，字符集 utf8mb4。
连接配置见 `config/config.go`（主机 / 端口 / 用户名 / 密码 / 库名）。
**建库建表与初始数据 SQL 不写入代码，由使用者手动执行**（见 4.3）。

### 4.1 用户表 tbl_users

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT UNSIGNED | PRIMARY KEY AUTO_INCREMENT | 主键 |
| username | VARCHAR(50) | NOT NULL UNIQUE | 用户名 |
| password | VARCHAR(32) | NOT NULL | 密码（MD5 密文） |
| real_name | VARCHAR(50) | | 真实姓名 |
| role | VARCHAR(20) | DEFAULT 'admin' | 角色 |
| status | INT | DEFAULT 1 | 状态：1 启用 / 0 禁用 |
| last_login | DATETIME | | 最后登录时间 |
| created_at | DATETIME | | 创建时间 |
| updated_at | DATETIME | | 更新时间 |
| deleted_at | DATETIME | | 软删除标记（已建索引） |

存储引擎 InnoDB，字符集 utf8mb4。

### 4.2 与 GORM 模型的映射

`models/user.go` 中的 `User` 结构体按 GORM 约定映射 `users` 表（复数表名），
字段 `Password` 标记 `json:"-"`，接口输出时自动隐藏密码密文。

### 4.3 初始化 SQL（手动执行）

> 执行方式：任选其一
> 1. 命令行：`mysql -u root -p < docs/init.sql`
> 2. 图形工具（如 Navicat）连接 MySQL 后粘贴执行

```sql
-- 0. 创建数据库（已存在则跳过）
CREATE DATABASE IF NOT EXISTS `sms` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
USE `sms`;

-- 1. 用户表
CREATE TABLE IF NOT EXISTS `users` (
  `id`         INT UNSIGNED NOT NULL AUTO_INCREMENT,
  `username`   VARCHAR(50) NOT NULL,
  `password`   VARCHAR(32) NOT NULL,
  `real_name`  VARCHAR(50) DEFAULT NULL,
  `role`       VARCHAR(20) DEFAULT 'admin',
  `status`     INT DEFAULT 1,
  `last_login` DATETIME DEFAULT NULL,
  `created_at` DATETIME DEFAULT NULL,
  `updated_at` DATETIME DEFAULT NULL,
  `deleted_at` DATETIME DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_tbl_users_username` (`username`),
  KEY `idx_tbl_users_deleted_at` (`deleted_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 2. 默认管理员：admin / admin123
--    密码密文 = MD5('admin123') = 0192023a7bbd73250516f069df18b500
INSERT INTO `users`
  (`username`, `password`, `real_name`, `role`, `status`, `created_at`, `updated_at`)
VALUES
  ('admin', '0192023a7bbd73250516f069df18b500', '系统管理员', 'admin', 1, NOW(), NOW());
```

## 5. 接口设计（已完成部分）

| 方法 | 路径 | 说明 | 鉴权 |
|---|---|---|---|
| GET | /login | 渲染登录页（已登录则跳转 /） | 公开 |
| POST | /login | 处理登录表单（username, password） | 公开 |
| GET | / | 后台管理首页 | 需登录 |
| GET | /logout | 登出并清空会话 | 需登录 |
| GET | /users | 用户列表（分页，keyword 用户名/姓名模糊搜索） | 需登录 |
| GET | /users/add | 渲染新增用户表单 | 需登录 |
| POST | /users/add | 提交新增用户（密码 ≥6 位 MD5 入库，用户名唯一校验） | 需登录 |
| GET | /users/edit/:id | 渲染编辑用户表单 | 需登录 |
| POST | /users/edit/:id | 提交编辑用户（密码留空不修改；改用户名时唯一校验） | 需登录 |

## 6. 配置说明（config/config.go）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| Port | 8080 | 服务监听端口 |
| DBHost / DBPort | 127.0.0.1 / 3306 | MySQL 地址 |
| DBUser / DBPassword | root / 见代码 | MySQL 账号密码（按实际环境修改） |
| DBName | sms | MySQL 库名 |
| SessionKey | （见代码） | 会话 Cookie 加密密钥，生产环境务必修改 |
| SessionMaxAge | 86400 | 会话有效期（秒），默认 24 小时 |

## 7. 部署与运行

```bash
# 编译运行
go build -o sms.exe .
./sms.exe

# 或开发模式
go run main.go
```

访问 http://localhost:8080/login ，默认账号 `admin / admin123`。

**首次部署步骤**：
1. 修改 `config/config.go` 中的 MySQL 密码为你本机的实际密码
2. 手动执行 `docs/init.sql` 初始化数据库（建库、建表、写入默认管理员）
3. 启动服务，使用 admin / admin123 登录
